# 02 · 设计规范（Design Tokens）

数值单位为设计稿 px（宽 375）。小程序里 **1px = 2rpx**。机器可读版本见 `tokens/tokens.json` 和 `tokens/tokens.wxss`。

## 1. 颜色

来自 Figma 变量集合「旅账 v2 · Color」，v2 里的所有颜色都已绑定到这些变量。**不要在代码里写其他颜色。**

| Token | 值 | 用途 |
|---|---|---|
| `bg/page` | `#F6F4F0` | 页面背景、输入框底色、灰色状态标签底 |
| `bg/surface` | `#FFFFFF` | 卡片、次按钮、主按钮上的文字 |
| `bg/subtle` | `#ECE8E1` | 次按钮描边、分隔线（旧）、骨架屏、「平分」标签底 |
| `bg/disabled` | `#E3DFD7` | 禁用按钮底、开关关闭态 |
| `border/divider` | `#E4DFD6` | 列表分隔线、弹层把手 |
| `text/primary` | `#1A1A17` | 主文字、主按钮底色、「我」的头像底 |
| `text/secondary` | `#6B6A64` | 次要文字、标签（白底对比度 5.4:1） |
| `text/placeholder` | `#8F8C84` | 占位符、禁用按钮文字 |
| `brand/green` | `#2F5D4E` | 品牌色、应收金额、已结清、链接、03 汇总卡底色 |
| `brand/green-subtle` | `#E8EFEB` | 绿色浅底（标签、分摊卡、邀请提示） |
| `brand/green-border` | `#C9DCD3` | 绿卡上的次要文字、绿色分隔线、说明卡描边 |
| `status/pending` | `#8A5208` | 待收款 / 待邀请文字（琥珀） |
| `status/pending-bg` | `#FBEBD3` | 待收款 / 待邀请标签底 |
| `status/danger` | `#A3442E` | 错误、危险操作（撤销） |
| `status/danger-bg` | `#F6E5E0` | 错误提示条底 |

**颜色语义（必须遵守）：**
- 红色（`status/danger`）**只用于**错误和破坏性操作。
- 待处理（待收款、待付款、待邀请）用琥珀色。
- 应收的钱、已完成用品牌绿。
- 每个次要文字都要用 `text/secondary`，不要再用更浅的灰。

## 2. 字体

```css
font-family: -apple-system, "PingFang SC", "Noto Sans SC", "Helvetica Neue", sans-serif;
/* 所有金额 */
font-variant-numeric: tabular-nums;
```

## 6. 小程序实现约定

- 底部操作栏固定在底部：内边距上 14、左右 24、下 34。设计稿里下方的 34 就是 iPhone 的 Home Indicator 安全区，实现为 `padding-bottom: max(28rpx, env(safe-area-inset-bottom))`，没有安全区的机型至少留 14px。背景是从透明到 `bg/page` 的竖向渐变（22% 处变为不透明），让列表滚到底部时被柔和遮住。
- 页面内容底部留出底部栏高度 + 28 的空白，保证最后一项不被遮住。
- 底部弹层：遮罩 `#1A1A17` 45% 不透明度；弹层白底、顶部圆角 24、顶部把手 36×4。
- 卡片没有阴影，靠 `bg/surface` 与 `bg/page` 的底色差区分层级。
- 原生导航栏：`navigationBarBackgroundColor: #F6F4F0`，`navigationBarTextStyle: black`。
