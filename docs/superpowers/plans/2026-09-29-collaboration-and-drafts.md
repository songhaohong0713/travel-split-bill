# 协作权限与本地草稿实施计划

> 已获得产品确认：2026-09-29。

## 任务 1：后端与数据库授权

1. 为成员、消费创建者及旅行创建者的边界补充红灯测试。
2. 在非 CloudBase 路径中按 `owner_id` 限制消费更新/删除，并仅允许旅行创建者邀请、发布结算。
3. 新增独立 SQL 迁移，以 `CREATE OR REPLACE FUNCTION` 将相同规则写入 CloudBase RPC。
4. 让消费列表带回创建者归属标记，供前端显示自身可管理入口。

## 任务 2：前端本地草稿

1. 将“拍小票/手动录入”改为直接打开无 `expenseId` 的录入页。
2. 为无 `expenseId` 的表单增加按旅行本机保存、加载和保存成功清除。
3. 更新前端集成测试，证明未保存不会请求创建 API、草稿会恢复。

## 任务 3：入口与回归

1. 邀请入口仅对旅行创建者显示，文案移除“可修改和结算”。
2. 跑小程序和后端完整测试。
3. 执行 CloudBase 代码审查规则，提交、合并到 `main` 并推送远端。

## 部署交接

- 后端上线前，需先在 CloudBase PostgreSQL 控制台执行新 SQL 迁移，再部署 CloudBase Run。
- 小程序需在微信开发者工具重新编译/上传；不需要额外部署云服务。
