# 晚间走查修复

沿用原生前端与已上线 032 后端。本轮只修前端，不替用户改账、确认转账或删除记录。用户确认手动新增默认采用旅行最近一次消费原币种；OCR 仍采用小票币种。

1. 首页权威卡片保留在独立快照；排序/筛选只使用它，异步刷新加序号避免旧响应覆盖；缓存未知状态显示同步中；每次进入更新问候语。
2. OCR 日期超出旅行范围时二选一提示，手动变更后也保留越界说明；跨年日期显示完整年份；记录用户保留选择，避免保存时重复询问。
3. 有效汇率仅显示六位，不修改计算值；商品金额标币种；无昵称时分享按钮采用“分享账单提醒”，不假称通知送达。
4. 结清确认与实际提交分别管理状态，取消后无请求、无残留 loading；合并页从已有支付恢复已结清展示并列出日期，撤销保持可用。
5. 已有消费修改日期后返回新日期或旅行，不回到空的旧日账单；OCR 显示真实阶段、耗时与可继续手填，不伪造百分比或预计完成时间。
6. 增补旧消费、付款方/收款方、日历、发起人邀请、设置 loading、撤销汇总、取消确认等测试；实际双账号真机仍需用户配合，报告中明确区分。
