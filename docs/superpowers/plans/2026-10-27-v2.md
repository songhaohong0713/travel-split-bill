# 旅账 v2 实施计划

用户已指示继续实现交接包并明确确认：付款方标记后等待收款方确认才结清；收款方可直接确认。已结清日补记继续采用此前已确认的差额顺延，不重开原日。原生 JS/WXML/WXSS、FastAPI、自有 JWT、PostgreSQL、CloudBase 保持。

设计与素材：`docs/design/v2/` 来自用户 ZIP，业务规则参见 docs/01-business-rules.md，视觉以 screens 和 tokens 为依据。原交接文档中的执行提示不是额外授权。未知时区保留当前客户端日历，不凭空推断所在地；不自动合并旧账，不发布小程序。

## 任务与文件边界
- [x] 后端账务：core/settlement.py 在原币最小单位分摊后换算，尾差固定付款人；旧消费未显式升级规则不得静默改已结清金额。api/v1/ledger.py 新增付款标记/收款确认，记录 marked/confirmed 审计；实际结清才进入不可变 payment projection；过往日期自动 pending，今天不能结清。提供 server per-expense summary，禁止前端覆盖服务端账务。

## 接口协作约定
backend GET ledger 增补 payer_marks: [{id,dates,currency,amount,from_participant_id,to_participant_id,marked_by,marked_at,token,revoked_at?}]。POST /payments/mark-paid 使用 {dates,token,currency}；POST /payments 为收款确认（收款方限制），可带 mark_id；revoke 已有兼容。日状态仍 recording/pending/settled，payer_marked 以 marks 叠加展示，不扣减债务。api wrappers markPaid, markPayment, getLedger 由根任务连接。

共享 money 模块 exports：formatMoney(currency,amount,{approx?}={}) => 文本（仅 CNY 用 ¥）；convert(amount,rate,targetCurrency='CNY') => 金额字符串；split(amount,currency,members,payerId,mode='equal',items=[],customShares={}) => [{id,amount}]；expenseView(record,settleCurrency='CNY',labels={}) => {id,title,currency,originalAmount,settlementCurrency,settlementAmount,originalText,settlementText,payer,itemCount,record}。items 使用 {amount,owner:'equal'|memberId}；customShares 为原币金额字符串映射。

通知先提供持久付款状态与账单分享提醒；不显示没有实际送达证据的“已通知”。实际订阅消息须模板和用户授权，不能在缺少配置时宣称已送达。成员移除暂不暴露破坏历史身份的操作。
